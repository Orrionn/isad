# ИСАД — frontend

Интерфейс для backend из архива `isad_backend_starter.zip` (FastAPI).

## Запуск

1. Установить Node.js 20 LTS или новее.
2. Распаковать архив `isad_frontend.zip`.
3. Открыть терминал в папке `isad_frontend`.
4. Выполнить:

```bash
npm install
npm run dev
```

5. Открыть адрес, который покажет Vite (обычно `http://localhost:5173`).
6. Backend должен быть запущен на `http://localhost:8000`.

Vite уже настроен проксировать `/api` и `/health` на `localhost:8000`, поэтому для локальной разработки менять адрес API и настраивать CORS не требуется.

## Что реализовано

- загрузка DOCX (ограничения и проверка формата выполняются backend);
- список документов, поиск, выбор и удаление;
- запуск анализа и автоматическая проверка статуса каждые 2,5 секунды;
- отображение сводки, положений, предупреждений, сущностей, недостающей информации и ограничений;
- адаптивный интерфейс для компьютера и телефона.

## Важное ограничение текущего backend

В API пока нет метода получения списка анализов документа. Поэтому фронтенд показывает результат текущего запуска анализа в открытой сессии. После перезагрузки страницы документ останется в библиотеке, но уже сформированный отчёт автоматически не подгрузится. Для этого backend-команде стоит добавить `GET /api/v1/documents/{document_id}/analyses` или endpoint последнего отчёта.
