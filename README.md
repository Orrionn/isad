# ИСАД — интеллектуальная система анализа договоров аренды жилых помещений

## Назначение
Система принимает договор аренды жилого помещения, асинхронно
анализирует его с помощью внешнего API языковой модели и формирует структурированный
аналитический отчет: извлеченные сущности и условия, классификация пунктов,
предупреждения о потенциально проблемных фрагментах с привязкой к исходному тексту.

Система выполняет технический анализ текста и НЕ является юридическим заключением.

## Архитектура
DOCX → FastAPI → файловое хранилище + PostgreSQL → Redis/Celery → AI-воркер
→ извлечение текста → сегментация → LLM API → валидация (Pydantic)
→ детерминированные проверки → отчет в PostgreSQL → веб-интерфейс.

## Структура репозитория
- `backend/` — FastAPI, модели БД, миграции Alembic, AI-пайплайн (`app/ai`), воркер (`app/worker`)
- `frontend/` — веб-интерфейс (загрузка, статусы, отчёт)
- `docs/` — ТЗ, архитектурные схемы, регламенты
- `evaluation/` — тестовые договоры, эталонная разметка, метрики

## Быстрый старт
1. Скопировать `.env.example` → `.env`, заполнить `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.
2. `docker compose up --build`
3. Интерфейс: http://localhost:3000 (frontend), API: http://localhost:8000/docs

## Тестирование
`pytest` из каталога `backend/` (см. `backend/tests`).
